# Herominde adversarial corpus (imported, read-only upstream)

This directory is a working copy of Herominde's Fair-Play & Phase-Isolation
Contract and adversarial corpus, imported from `/workspace/scratch/hc-herominde/`
(which is kept read-only upstream). Add new red-team cheaters here; HC rules are
genuine semantic/lexical/AST/CFG/call-graph checks, never hardcoded filenames,
so new unseen cheaters are caught by the same rules.
